# Commandes console, guides, outils
(déplacé de CLAUDE.md le 24/10/2026 : chargé seulement quand on touche à ces fichiers)

- **Commandes console** (19/10/2026) : **`commands.json`** = la base de données (textes originaux en anglais écrits par Claude ; catégories ; `summary`, `description`, `syntax`, `values`, `default` seulement si fiable, `examples`, `related`, `cheat`, `status`, `replacement`, `page`). `status` : `active` / `removed` (héritée de CS:GO, ne marche plus) / `check` (pas encore vérifiée en jeu → **pas publiée**). build.js fabrique **`commands/index.html`** (liste, recherche instantanée, filtres par catégorie, `#crosshair` dans l'adresse = filtre direct, Copy, FAQ) + **`commands/<nom>.html`** pour chaque commande `page: true` (syntaxe, valeurs, exemples, comment l'utiliser, commandes liées, FAQ, JSON-LD TechArticle + BreadcrumbList + FAQPage ; les commandes de crosshair ont les **stats réelles des pros**). Les noms de commandes avec « _ » cités dans les textes deviennent des liens. Sources des faits : liste du wiki Valve (déc. 2025, incomplète et avec des « valeurs par défaut » parfois personnelles → ne pas s'y fier aveuglément) + commandes de crosshair du 30/09/2026 (librairie). **Ne jamais marquer une commande « removed » sans en être sûr** (absente du wiki ≠ supprimée) : en cas de doute, la mettre en `check` et demander à Anto de taper son nom dans la console (valeur affichée = existe ; « Unknown command » = supprimée). Vérifié en jeu le 19/10/2026 : existent encore cl_crosshairsize, cl_crosshairthickness, cl_crosshairalpha (anciennes, les codes utilisent les nouvelles), cl_interp, cl_interp_ratio, cl_hud_telemetry_frametime_show / _ping_show ; supprimées cl_crosshairgap, cl_crosshair_outlinethickness, cl_crosshaircolor, m_rawinput, m_customaccel, cl_updaterate, cl_cmdrate, voice_scale, mat_monitorgamma.
- **Guides** (19/10/2026) : **`guides.json`** = les guides (textes originaux en anglais : launch options, best settings, stretched, sensitivity, FPS boost, crosshair, aim training). Chaque guide : `slug`, `category`, `title`, `seoTitle` (≤ 65 caractères), `description`, `intro`, `sections` (blocs `p`, `list`, `steps`, `table`, `tip`, `copy`, `config`, `pro-crosshair-stats`, `pro-resolution-stats`, `sens-calc`), `faq`, `related`, `commands`. Mise en forme : `code` (lien auto si la commande a une page), **gras**, [texte](lien). build.js fabrique **`guides/index.html`** + **`guides/<slug>.html`** (sommaire « On this page », temps de lecture, JSON-LD Article + BreadcrumbList + FAQPage, liens vers les commandes ; chaque page de commande liste les guides qui en parlent). Les stats des pros (crosshair, résolution) sont recalculées à chaque build. Pas de guides grenades (trop long, décision d'Anto). Prudence : ne rien affirmer qui n'est pas sûr (menus CS2, options de lancement).
- **Outils** (19/10/2026) : **`tools/index.html`** (page des outils) + **`tools/bind-generator.html`** (générateur de binds, cible « cs2 bind generator »). Données dans **`binds.json`** (touches proposées, articles à acheter avec leur commande `buy`, réglages à basculer avec `toggle`, volume avec `incrementvar`, sélection de grenade `slot6`-`slot10`, autres actions, binds populaires). L'outil : touche (liste ou « Press a key » au clavier/souris), action (Buy, Jump throw, Toggle, Volume, Grenade, Other, Custom), bind en direct + Copy, « My binds » (une seule action par touche, gardé dans le navigateur), Copy all, téléchargement d'un `autoexec.cfg`. Page : binds populaires, liste de toutes les commandes buy, jump throw, FAQ, JSON-LD WebApplication + FAQPage + Breadcrumb. Le générateur de crosshair a maintenant le fil d'Ariane Home › Tools. **À faire vérifier en jeu par Anto** : un bind d'achat, le jump throw, un `toggle` et un `slotN` de grenade.
