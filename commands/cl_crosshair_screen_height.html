cl_crosshair_screen_height

Crosshair

Screen height the crosshair sizes are designed for. New in the CS2 update of September 30, 2026. Crosshair length, thickness and gap are now counted in pixels for this screen height. If you play at a different resolution, CS2 scales the crosshair so it keeps the same size relative to your screen. It is saved in every CS2 crosshair share code, which is why a pro's crosshair looks right on your screen too.

cl_crosshair_screen_height 1080

Syntax

cl_crosshair_screen_height <pixels>

ValueWhat it does
1080Made for a 1920×1080 screen
960Made for 1280×960 (4:3 stretched)
1440Made for a 2560×1440 screen

Examples

cl_crosshair_screen_height 1080
cl_crosshair_screen_height 960

How to use cl_crosshair_screen_height in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
