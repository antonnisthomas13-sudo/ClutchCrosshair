cl_crosshair_sniper_width

Crosshair

Thickness of the sniper scope lines. Makes the black lines of the AWP and Scout scopes thicker. 1 keeps the thin single-pixel lines; higher values make the scope cross easier to see.

cl_crosshair_sniper_width 2

Syntax

cl_crosshair_sniper_width <1+> · Default value: 1

ValueWhat it does
1Thin hairline
2Thicker lines

Examples

cl_crosshair_sniper_width 2

How to use cl_crosshair_sniper_width in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
