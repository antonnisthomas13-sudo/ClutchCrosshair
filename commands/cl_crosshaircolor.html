cl_crosshaircolor

CrosshairRemoved in CS2

Removed in CS2: the preset colors are gone.

What to use instead in CS2

cl_crosshaircolor, which picked one of five preset colors, no longer exists in CS2. Set any color you want with cl_crosshaircolor_r, cl_crosshaircolor_g and cl_crosshaircolor_b, from 0 to 255 each.

Use cl_crosshaircolor_r instead: red part of a custom crosshair color (0-255).

cl_crosshaircolor_r 0; cl_crosshaircolor_g 255; cl_crosshaircolor_b 255

cl_crosshaircolor FAQ

What does cl_crosshaircolor do in CS2?

Removed in CS2: the preset colors are gone. cl_crosshaircolor, which picked one of five preset colors, no longer exists in CS2. Set any color you want with cl_crosshaircolor_r, cl_crosshaircolor_g and cl_crosshaircolor_b, from 0 to 255 each.

Does cl_crosshaircolor work in CS2?

No. cl_crosshaircolor was a CS:GO command and does not exist in CS2. Use cl_crosshaircolor_r instead.
