cl_crosshaircolor_r

Crosshair

Red part of a custom crosshair color (0-255). With cl_crosshaircolor_g and cl_crosshaircolor_b, sets the exact color of your crosshair as red, green and blue values from 0 to 255. For example 0 255 255 gives cyan and 0 255 0 gives pure green, two of the most popular colors among CS2 pros.

cl_crosshaircolor_r 0; cl_crosshaircolor_g 255; cl_crosshaircolor_b 255

Syntax

cl_crosshaircolor_r <0-255>

ValueWhat it does
0 255 0Green (r g b)
0 255 255Cyan
255 255 0Yellow

Examples

cl_crosshaircolor_r 0; cl_crosshaircolor_g 255; cl_crosshaircolor_b 255

How to use cl_crosshaircolor_r in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
