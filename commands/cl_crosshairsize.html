cl_crosshairsize

Crosshair

Old crosshair length setting, still in the console. cl_crosshairsize still exists in the CS2 console, but since the update of September 30, 2026 the crosshair length is set in real pixels with cl_crosshair_length. That is the command saved in every new CS2 crosshair code, so use cl_crosshair_length for a crosshair that looks the same on every screen.

cl_crosshair_length 2

Syntax

cl_crosshairsize <value>

Examples

cl_crosshair_length 2

How to use cl_crosshairsize in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

cl_crosshairsize FAQ

What does cl_crosshairsize do in CS2?

Old crosshair length setting, still in the console. cl_crosshairsize still exists in the CS2 console, but since the update of September 30, 2026 the crosshair length is set in real pixels with cl_crosshair_length. That is the command saved in every new CS2 crosshair code, so use cl_crosshair_length for a crosshair that looks the same on every screen.

Does cl_crosshairsize need sv_cheats?

No. cl_crosshairsize works without sv_cheats, including in official matchmaking.
