cl_crosshairthickness

Crosshair

Old crosshair thickness setting, still in the console. cl_crosshairthickness still exists in the CS2 console, but since the update of September 30, 2026 the thickness is set in real pixels with cl_crosshair_thickness, the command saved in CS2 crosshair codes. Use cl_crosshair_thickness to copy a pro's crosshair exactly.

cl_crosshair_thickness 2

Syntax

cl_crosshairthickness <value>

Examples

cl_crosshair_thickness 2

How to use cl_crosshairthickness in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
