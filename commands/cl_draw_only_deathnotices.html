cl_draw_only_deathnotices

HUD & radar

Hides the HUD except the crosshair and kill feed. Hides almost the whole HUD and keeps only the crosshair and the kill feed. It is made for clean videos and screenshots, and it works without sv_cheats.

cl_draw_only_deathnotices 1

Syntax

cl_draw_only_deathnotices <0|1> · Default value: 0

ValueWhat it does
0Normal HUD
1Only crosshair and kill feed

Examples

cl_draw_only_deathnotices 1

How to use cl_draw_only_deathnotices in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

cl_draw_only_deathnotices FAQ

What does cl_draw_only_deathnotices do in CS2?

Hides the HUD except the crosshair and kill feed. Hides almost the whole HUD and keeps only the crosshair and the kill feed. It is made for clean videos and screenshots, and it works without sv_cheats.

What is the default value of cl_draw_only_deathnotices?

The default value of cl_draw_only_deathnotices in CS2 is 0.

Does cl_draw_only_deathnotices need sv_cheats?

No. cl_draw_only_deathnotices works without sv_cheats, including in official matchmaking.
