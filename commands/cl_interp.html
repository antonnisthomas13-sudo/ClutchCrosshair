cl_interp

Network

Shows the interpolation used by the game. In CS2, cl_interp mostly shows the interpolation the game uses, together with cl_interp_ratio and the server update rate (for example cl_interp = 0 with cl_updaterate=64). CS2 manages interpolation for you with its sub-tick system, so there is no need to tweak it like in CS:GO.

How to use cl_interp in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

cl_interp FAQ

What does cl_interp do in CS2?

Shows the interpolation used by the game. In CS2, cl_interp mostly shows the interpolation the game uses, together with cl_interp_ratio and the server update rate (for example cl_interp = 0 with cl_updaterate=64). CS2 manages interpolation for you with its sub-tick system, so there is no need to tweak it like in CS:GO.

Does cl_interp need sv_cheats?

No. cl_interp works without sv_cheats, including in official matchmaking.
