cl_interp_ratio

Network

Interpolation ratio, managed by CS2. cl_interp_ratio still exists in CS2, with a value of 0 by default. Unlike in CS:GO, interpolation is handled by the game's sub-tick system, so most players should leave it at its default value.

cl_interp_ratio 0

Syntax

cl_interp_ratio <value> · Default value: 0

Examples

cl_interp_ratio 0

How to use cl_interp_ratio in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

cl_interp_ratio FAQ

What does cl_interp_ratio do in CS2?

Interpolation ratio, managed by CS2. cl_interp_ratio still exists in CS2, with a value of 0 by default. Unlike in CS:GO, interpolation is handled by the game's sub-tick system, so most players should leave it at its default value.

What is the default value of cl_interp_ratio?

The default value of cl_interp_ratio in CS2 is 0.

Does cl_interp_ratio need sv_cheats?

No. cl_interp_ratio works without sv_cheats, including in official matchmaking.
