cl_showfps

HUD & radar

Shows your FPS on screen. Displays your frames per second at the top of the screen. Use 1 for the live value or 2 for a smoothed value that is easier to read.

cl_showfps 1

Syntax

cl_showfps <0-4> · Default value: 0

ValueWhat it does
0Off
1FPS
2Smoothed FPS
3Server frame time
4FPS and log to a file

Examples

cl_showfps 1
cl_showfps 0

How to use cl_showfps in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
