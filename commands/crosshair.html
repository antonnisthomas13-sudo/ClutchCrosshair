crosshair

Crosshair

Shows or hides your crosshair. Turns the crosshair on (1) or off (0). Hiding it is mostly useful for clean screenshots and videos; in a real match you always want it on.

crosshair 0

Syntax

crosshair <0|1> · Default value: 1

ValueWhat it does
1Crosshair visible
0Crosshair hidden

Examples

crosshair 0
crosshair 1

How to use crosshair in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

crosshair FAQ

What does crosshair do in CS2?

Shows or hides your crosshair. Turns the crosshair on (1) or off (0). Hiding it is mostly useful for clean screenshots and videos; in a real match you always want it on.

What is the default value of crosshair?

The default value of crosshair in CS2 is 1.

Does crosshair need sv_cheats?

No. crosshair works without sv_cheats, including in official matchmaking.
