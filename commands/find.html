find

General

Searches commands by name or description. Lists every command whose name or help text contains your search. Great to discover commands, for example find crosshair.

find crosshair

Syntax

find <text>

Examples

find crosshair
find radar

How to use find in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
