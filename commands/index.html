CS2 console FAQ

How do I open the console in CS2?

Go to Settings › Game and set Enable Developer Console to Yes. Then press the ~ key (under Escape) in game to open it. If your keyboard has no ~ key, bind toggleconsole to another key.

Do console commands work in competitive matchmaking?

Most commands that change your own settings (crosshair, HUD, radar, mouse, audio) work everywhere. Commands marked Needs sv_cheats, and server commands starting with mp_ or bot_, only work on a server you host, for example a private match with bots.

How do I save my console commands?

Put them in a file named autoexec.cfg in the game's cfg folder (game/csgo/cfg) and add +exec autoexec to your launch options, or type exec autoexec in the console.

Why does a CS:GO command not work in CS2?

Many CS:GO commands were removed or renamed in CS2, such as net_graph. Commands marked Removed in CS2 on this page tell you what to use instead.
