m_rawinput

MouseRemoved in CS2

Removed in CS2: raw mouse input is always on.

What to use instead in CS2

In CS:GO, m_rawinput 1 made the game read your mouse directly. CS2 always does this, so the command was removed and typing it returns Unknown command. Nothing to change: your mouse already uses raw input.

Use sensitivity instead: your mouse sensitivity.

m_rawinput FAQ

What does m_rawinput do in CS2?

Removed in CS2: raw mouse input is always on. In CS:GO, m_rawinput 1 made the game read your mouse directly. CS2 always does this, so the command was removed and typing it returns Unknown command. Nothing to change: your mouse already uses raw input.

Does m_rawinput work in CS2?

No. m_rawinput was a CS:GO command and does not exist in CS2. Use sensitivity instead.
