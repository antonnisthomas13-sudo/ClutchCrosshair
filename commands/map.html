map

General

Loads a map on your own server. Starts a local server on the map you choose, for example to practice alone. Official map names start with de_ (de_mirage, de_dust2, de_inferno...).

map de_mirage

Syntax

map <map_name>

Examples

map de_mirage
map de_dust2

How to use map in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
