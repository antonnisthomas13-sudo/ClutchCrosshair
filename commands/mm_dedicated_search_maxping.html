mm_dedicated_search_maxping

Network

Highest ping allowed when searching for a match. Sets the highest ping you accept for matchmaking servers, in milliseconds. A lower value finds servers closer to you, but the queue can take longer.

mm_dedicated_search_maxping 60

Syntax

mm_dedicated_search_maxping <milliseconds> · Default value: 150

Examples

mm_dedicated_search_maxping 60

How to use mm_dedicated_search_maxping in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
