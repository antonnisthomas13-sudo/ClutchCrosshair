mp_buy_anywhere

Practice & server

Lets you buy anywhere on the map. Allows buying outside the buy zone: 1 for both teams, 2 for Terrorists only, 3 for Counter-Terrorists only. Perfect for grenade practice.

mp_buy_anywhere 1

Syntax

mp_buy_anywhere <0-3> · Default value: 0

ValueWhat it does
0Buy zone only
1Both teams
2Terrorists
3Counter-Terrorists

Examples

mp_buy_anywhere 1

How to use mp_buy_anywhere in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
