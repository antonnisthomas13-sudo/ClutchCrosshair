playdemo

General

Plays a demo file. Plays a recorded demo (.dem). Put the file in the csgo folder of the game and type its name. ClutchCrosshair reads pro crosshairs from official match demos the same way.

playdemo mymatch

Syntax

playdemo <name>

Examples

playdemo mymatch

How to use playdemo in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
