rate

Network

Maximum data your connection can receive. Tells the server how many bytes per second your connection can receive. The default 786432 (about 6 Mbps) is the maximum and is right for almost every connection; only lower it on a very slow or unstable connection.

rate 786432

Syntax

rate <bytes per second> · Default value: 786432

Examples

rate 786432

How to use rate in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
