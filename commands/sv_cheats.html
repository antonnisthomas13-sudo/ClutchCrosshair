sv_cheats

Practice & server

Enables cheat commands on your server. Allows commands marked as cheats (noclip, god, sv_rethrow_last_grenade, cl_showpos...). It only works on a server you host, such as a private match with bots, never in official matchmaking.

sv_cheats 1

Syntax

sv_cheats <0|1> · Default value: 0

ValueWhat it does
0Cheats off
1Cheats on (your own server only)

Examples

sv_cheats 1

How to use sv_cheats in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

sv_cheats FAQ

What does sv_cheats do in CS2?

Enables cheat commands on your server. Allows commands marked as cheats (noclip, god, sv_rethrow_last_grenade, cl_showpos...). It only works on a server you host, such as a private match with bots, never in official matchmaking.

What is the default value of sv_cheats?

The default value of sv_cheats in CS2 is 0.

Does sv_cheats need sv_cheats?

No. sv_cheats works without sv_cheats, including in official matchmaking.
