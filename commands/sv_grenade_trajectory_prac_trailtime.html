sv_grenade_trajectory_prac_trailtime

Practice & server

Shows the path of thrown grenades. Draws the trajectory of each grenade you throw and keeps it visible for this number of seconds. Use 10 or more to compare two throws.

sv_grenade_trajectory_prac_trailtime 10

Syntax

sv_grenade_trajectory_prac_trailtime <seconds> · Default value: 0

Examples

sv_grenade_trajectory_prac_trailtime 10

How to use sv_grenade_trajectory_prac_trailtime in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
