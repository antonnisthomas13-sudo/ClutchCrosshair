sv_infinite_ammo

Practice & serverNeeds sv_cheats

Infinite ammo and grenades. With 1, your magazine never empties; with 2, you never run out of ammo but still have to reload. It also gives infinite grenades, which makes it the base of every grenade practice config. Needs sv_cheats 1.

sv_cheats 1; sv_infinite_ammo 1

Syntax

sv_infinite_ammo <0-2> · Default value: 0

ValueWhat it does
0Normal
1Infinite ammo, no reload
2Infinite ammo, with reload

This command needs sv_cheats 1: it only works on a server you host, never in official matchmaking.

Examples

sv_cheats 1; sv_infinite_ammo 1

How to use sv_infinite_ammo in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

sv_infinite_ammo FAQ

What does sv_infinite_ammo do in CS2?

Infinite ammo and grenades. With 1, your magazine never empties; with 2, you never run out of ammo but still have to reload. It also gives infinite grenades, which makes it the base of every grenade practice config. Needs sv_cheats 1.

What is the default value of sv_infinite_ammo?

The default value of sv_infinite_ammo in CS2 is 0.

Does sv_infinite_ammo need sv_cheats?

Yes. sv_infinite_ammo only works with sv_cheats 1, on a server you host (a private match with bots, for example), never in official matchmaking.
