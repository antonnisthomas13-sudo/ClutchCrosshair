sv_rethrow_last_grenade

Practice & serverNeeds sv_cheats

Throws your last grenade again. Throws the last grenade again from exactly the same spot, so you can watch where it lands without walking back. Needs sv_cheats 1; it is often bound to a key in practice configs.

sv_rethrow_last_grenade

Syntax

sv_rethrow_last_grenade

This command needs sv_cheats 1: it only works on a server you host, never in official matchmaking.

Examples

sv_rethrow_last_grenade
bind x sv_rethrow_last_grenade

How to use sv_rethrow_last_grenade in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

sv_rethrow_last_grenade FAQ

What does sv_rethrow_last_grenade do in CS2?

Throws your last grenade again. Throws the last grenade again from exactly the same spot, so you can watch where it lands without walking back. Needs sv_cheats 1; it is often bound to a key in practice configs.

Does sv_rethrow_last_grenade need sv_cheats?

Yes. sv_rethrow_last_grenade only works with sv_cheats 1, on a server you host (a private match with bots, for example), never in official matchmaking.
