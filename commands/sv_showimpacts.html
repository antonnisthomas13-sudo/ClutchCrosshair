sv_showimpacts

Practice & server

Shows where your bullets hit. Draws a box where each bullet lands: red for what your game saw, blue for what the server saw. It is great to learn spray patterns on a wall.

sv_showimpacts 1

Syntax

sv_showimpacts <0-3> · Default value: 0

ValueWhat it does
0Off
1Client and server
2Client only
3Server only

Examples

sv_showimpacts 1

How to use sv_showimpacts in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
