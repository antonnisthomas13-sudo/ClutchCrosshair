viewmodel_offset_x

Viewmodel

Moves the weapon left or right. Moves your weapon model horizontally, from -2.5 to 2.5. Higher values push the gun to the right edge of the screen.

viewmodel_offset_x 2.5

Syntax

viewmodel_offset_x <-2.5 to 2.5> · Default value: 1

Examples

viewmodel_offset_x 2.5

How to use viewmodel_offset_x in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.

The default value of viewmodel_offset_x in CS2 is 1.
