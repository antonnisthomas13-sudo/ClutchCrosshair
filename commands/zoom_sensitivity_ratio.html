zoom_sensitivity_ratio

Mouse

Mouse sensitivity when scoped. Multiplies your sensitivity when you zoom in with a scoped weapon such as the AWP. 1 is the default; lower values make scoped aiming slower and more precise.

zoom_sensitivity_ratio 0.9

Syntax

zoom_sensitivity_ratio <value> · Default value: 1

Examples

zoom_sensitivity_ratio 0.9

How to use zoom_sensitivity_ratio in CS2

  1. Enable the developer console in Settings › Game › Enable Developer Console.
  2. Press ~ to open the console, type the command and press Enter.
  3. To apply it every time you launch CS2, add the line to an autoexec.cfg file in your cfg folder.
