cl_crosshair_screen_height

Crosshair

Altura de pantalla para la que están pensados los tamaños del crosshair. Nuevo en la actualización de CS2 del 30 de septiembre de 2026. La longitud, el grosor y la separación del crosshair se cuentan ahora en píxeles para esta altura de pantalla. Si juegas con otra resolución, CS2 escala el crosshair para que mantenga el mismo tamaño en relación con tu pantalla. Se guarda en cada código de crosshair de CS2, por eso el crosshair de un pro también se ve bien en tu pantalla.

cl_crosshair_screen_height 1080

Sintaxis

cl_crosshair_screen_height <pixels>

ValorQué hace
1080Pensado para una pantalla de 1920×1080
960Pensado para 1280×960 (4:3 estirado)
1440Pensado para una pantalla de 2560×1440

Ejemplos

cl_crosshair_screen_height 1080
cl_crosshair_screen_height 960

Cómo usar cl_crosshair_screen_height en CS2

  1. Activa la consola de desarrollador en Ajustes › Juego › Activar consola de desarrollador.
  2. Pulsa ~ (la tecla debajo de Esc) para abrir la consola, escribe el comando y pulsa Enter.
  3. Para aplicarlo cada vez que abras CS2, añade la línea a un archivo autoexec.cfg en tu carpeta cfg.
