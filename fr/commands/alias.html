alias

Général

Crée une commande perso. Donne un nom à une liste de commandes, pour toutes les lancer d'un coup ou les associer à une touche. Un alias dont le nom commence par + s'exécute quand tu appuies sur la touche, et l'alias - correspondant quand tu la relâches : c'est comme ça que marche le bind de jump throw. Mets-le dans ton autoexec.cfg pour qu'il se charge à chaque lancement de CS2.

alias prac "sv_cheats 1; sv_infinite_ammo 1; mp_buy_anywhere 1"

Syntaxe

alias <name> "<commands>"

Exemples

alias prac "sv_cheats 1; sv_infinite_ammo 1; mp_buy_anywhere 1"
alias "+jumpthrow" "+jump;-attack;-attack2"
alias "-jumpthrow" "-jump"
bind alt "+jumpthrow"

Comment utiliser alias dans CS2

  1. Active la console développeur dans Paramètres › Jeu › Activer la console développeur.
  2. Appuie sur ² (clavier AZERTY) ou ~ (QWERTY) pour ouvrir la console, tape la commande puis appuie sur Entrée.
  3. Pour l'appliquer à chaque lancement de CS2, ajoute la ligne dans un fichier autoexec.cfg de ton dossier cfg.

FAQ : alias

À quoi sert alias dans CS2 ?

Crée une commande perso. Donne un nom à une liste de commandes, pour toutes les lancer d'un coup ou les associer à une touche. Un alias dont le nom commence par + s'exécute quand tu appuies sur la touche, et l'alias - correspondant quand tu la relâches : c'est comme ça que marche le bind de jump throw. Mets-le dans ton autoexec.cfg pour qu'il se charge à chaque lancement de CS2.

Est-ce que alias nécessite sv_cheats ?

Non. alias marche sans sv_cheats, y compris en matchmaking officiel.
