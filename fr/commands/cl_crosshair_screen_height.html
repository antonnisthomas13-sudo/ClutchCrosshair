cl_crosshair_screen_height

Crosshair

Hauteur d'écran pour laquelle les tailles du crosshair sont prévues. Nouveauté de la mise à jour CS2 du 30 septembre 2026. La longueur, l'épaisseur et l'écart du crosshair se comptent maintenant en pixels pour cette hauteur d'écran. Si tu joues dans une autre résolution, CS2 adapte le crosshair pour qu'il garde la même taille par rapport à ton écran. Elle est enregistrée dans chaque code de crosshair CS2 : c'est pour ça que le crosshair d'un pro s'affiche correctement sur ton écran aussi.

cl_crosshair_screen_height 1080

Syntaxe

cl_crosshair_screen_height <pixels>

ValeurCe qu'elle fait
1080Prévu pour un écran 1920×1080
960Prévu pour du 1280×960 (4:3 étiré)
1440Prévu pour un écran 2560×1440

Exemples

cl_crosshair_screen_height 1080
cl_crosshair_screen_height 960

Comment utiliser cl_crosshair_screen_height dans CS2

  1. Active la console développeur dans Paramètres › Jeu › Activer la console développeur.
  2. Appuie sur ² (clavier AZERTY) ou ~ (QWERTY) pour ouvrir la console, tape la commande puis appuie sur Entrée.
  3. Pour l'appliquer à chaque lancement de CS2, ajoute la ligne dans un fichier autoexec.cfg de ton dossier cfg.
