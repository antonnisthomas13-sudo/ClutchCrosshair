map

Général

Charge une map sur ton propre serveur. Lance un serveur local sur la map de ton choix, par exemple pour t'entraîner seul. Les noms des maps officielles commencent par de_ (de_mirage, de_dust2, de_inferno...).

map de_mirage

Syntaxe

map <map_name>

Exemples

map de_mirage
map de_dust2

Comment utiliser map dans CS2

  1. Active la console développeur dans Paramètres › Jeu › Activer la console développeur.
  2. Appuie sur ² (clavier AZERTY) ou ~ (QWERTY) pour ouvrir la console, tape la commande puis appuie sur Entrée.
  3. Pour l'appliquer à chaque lancement de CS2, ajoute la ligne dans un fichier autoexec.cfg de ton dossier cfg.

FAQ : map

À quoi sert map dans CS2 ?

Charge une map sur ton propre serveur. Lance un serveur local sur la map de ton choix, par exemple pour t'entraîner seul. Les noms des maps officielles commencent par de_ (de_mirage, de_dust2, de_inferno...).

Est-ce que map nécessite sv_cheats ?

Non. map marche sans sv_cheats, y compris en matchmaking officiel.
