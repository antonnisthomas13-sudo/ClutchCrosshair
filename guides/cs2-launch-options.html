Best CS2 Launch Options (2026)

Settings · Updated 19/10/2026 · 2 min read

Launch options are small commands that Steam passes to CS2 when the game starts. A few of them are genuinely useful, but most of the long lists you find online were made for CS:GO and do nothing in CS2. Here are the ones worth using, and the myths to forget.

How to add launch options in Steam

  1. Open your Steam Library and right-click Counter-Strike 2.
  2. Click Properties, then stay on the General tab.
  3. Type your options in the Launch Options field, separated by spaces.
  4. Close the window and start CS2: the options apply right away.

Options that start with a minus sign (-console) are launch parameters. Options that start with a plus sign (+exec autoexec) run a console command when the game starts.

The launch options worth using

Launch optionWhat it does
-consoleOpens the developer console as soon as the game starts. Handy if you use it often.
+exec autoexecRuns your autoexec.cfg file at every launch, so your settings and binds are always applied.
-fullscreenForces exclusive fullscreen, usually the mode with the lowest input delay.
-w 1280 -h 960Forces a resolution (width and height). Useful if the game starts in the wrong resolution.
-freq 240Asks for a refresh rate in Hz. Use the real refresh rate of your monitor.
-vulkanStarts CS2 with the Vulkan renderer instead of DirectX on Windows. It can help or hurt depending on your PC, so compare your FPS.
-allow_third_party_softwareLets software that hooks into the game (some recording or overlay tools) work. Only add it if a tool needs it.

A simple, safe set for most players looks like this:

-console +exec autoexec -fullscreen

Launch options that do nothing in CS2

These come from old CS:GO guides. They are harmless at best, and some can make things worse:

Old optionWhy to remove it
-highForces a high CPU priority. Modern Windows already gives the game what it needs, and it can make background apps like voice chat stutter.
-threadsCS2 detects your CPU cores on its own; forcing a number usually lowers performance.
-tickrate 128Official CS2 servers run at 64 tick with sub-tick updates; this option does not change matchmaking.
-novidSkipped the intro video in CS:GO. CS2 has no intro video to skip.
-d3d9ex, +mat_queue_mode 2, +cl_forcepreload 1Settings of the old Source 1 engine. CS2 runs on Source 2 and ignores them.

If your game behaves strangely, the first thing to try is an empty Launch Options field.

Launch options and the console: what is the difference?

Most settings are better placed in an autoexec file than in launch options. Create a file named autoexec.cfg in Counter-Strike Global Offensive/game/csgo/cfg, write one command per line (for example fps_max 0 or your crosshair commands), then add +exec autoexec to your launch options. You can find every useful command in our CS2 console commands list.

Best CS2 Launch Options FAQ

What are the best CS2 launch options?

Keep it short: -console to open the console, +exec autoexec to load your settings, and -fullscreen. Add -w, -h or -freq only if the game starts with the wrong resolution or refresh rate.

Does -high increase FPS in CS2?

No. It only changes the CPU priority of the game, which modern Windows already handles well, and it can make other programs stutter.

Does -tickrate 128 work in CS2?

No. Official CS2 servers use 64 tick with sub-tick updates, and the launch option does not change matchmaking.

Where do I put launch options for CS2?

In Steam: right-click Counter-Strike 2 in your library, then Properties › General › Launch Options.
