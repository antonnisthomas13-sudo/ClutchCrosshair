CS2 crosshair FAQ

How do I import a crosshair code in CS2?

Copy the share code, then in CS2 open Settings › Game › Crosshair, click Share or Import and paste the code. You can also copy the console commands and paste them in the CS2 console (~).

Why don't old CSGO- crosshair codes work anymore?

Since the CS2 update of September 30, 2026, crosshair share codes use a new format starting with CS (without dashes). Old CSGO-xxxxx codes can no longer be imported. Every code on ClutchCrosshair uses the new CS2 format.

Where do these pro crosshair codes come from?

They are read directly from official CS2 match demos, so each code is the exact crosshair the player used in a recent official match.

Most CS2 pros use a small static crosshair without outline, usually green or cyan, with a small gap. Browse the pro list above to compare them with a live preview.
