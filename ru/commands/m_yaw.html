m_yaw

Мышь

Множитель горизонтальной скорости мыши. Умножает горизонтальное движение мыши. Значение по умолчанию 0.022 совпадает с вертикальной скоростью. Игроки на 4:3 растянутом иногда уменьшают его, чтобы компенсировать более широкую картинку, но большинство оставляет стандарт.

m_yaw 0.022

Синтаксис

m_yaw <value> · По умолчанию: 0.022

Примеры

m_yaw 0.022

Как использовать m_yaw в CS2

  1. Включите консоль разработчика: Настройки › Игра › Включить консоль разработчика.
  2. Нажмите ~ (клавиша Ё под Esc), чтобы открыть консоль, введите команду и нажмите Enter.
  3. Чтобы команда применялась при каждом запуске CS2, добавьте строку в файл autoexec.cfg в папке cfg.

FAQ: m_yaw

Что делает m_yaw в CS2?

Множитель горизонтальной скорости мыши. Умножает горизонтальное движение мыши. Значение по умолчанию 0.022 совпадает с вертикальной скоростью. Игроки на 4:3 растянутом иногда уменьшают его, чтобы компенсировать более широкую картинку, но большинство оставляет стандарт.

Какое значение m_yaw по умолчанию?

Значение m_yaw по умолчанию в CS2: 0.022.

Нужен ли sv_cheats для m_yaw?

Нет. m_yaw работает без sv_cheats, в том числе в официальном матчмейкинге.
