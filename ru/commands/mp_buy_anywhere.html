mp_buy_anywhere

Тренировка и сервер

Покупка в любом месте карты. Разрешает покупку вне зоны закупки: 1 — для обеих команд, 2 — только для террористов, 3 — только для спецназа. Идеально для тренировки гранат.

mp_buy_anywhere 1

Синтаксис

mp_buy_anywhere <0-3> · По умолчанию: 0

ЗначениеЧто делает
0Только в зоне закупки
1Обе команды
2Террористы
3Спецназ

Примеры

mp_buy_anywhere 1

Как использовать mp_buy_anywhere в CS2

  1. Включите консоль разработчика: Настройки › Игра › Включить консоль разработчика.
  2. Нажмите ~ (клавиша Ё под Esc), чтобы открыть консоль, введите команду и нажмите Enter.
  3. Чтобы команда применялась при каждом запуске CS2, добавьте строку в файл autoexec.cfg в папке cfg.

FAQ: mp_buy_anywhere

Что делает mp_buy_anywhere в CS2?

Покупка в любом месте карты. Разрешает покупку вне зоны закупки: 1 — для обеих команд, 2 — только для террористов, 3 — только для спецназа. Идеально для тренировки гранат.

Какое значение mp_buy_anywhere по умолчанию?

Значение mp_buy_anywhere по умолчанию в CS2: 0.

Нужен ли sv_cheats для mp_buy_anywhere?

Нет. mp_buy_anywhere работает без sv_cheats, в том числе в официальном матчмейкинге.
